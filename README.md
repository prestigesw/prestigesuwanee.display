# Prestige Institute Digital Signage

This repository contains the contents of a personalized digital signage for Prestige Institute's Suwanee location. Written entirely in an HTML file, this code runs locally on a browser to display information.

This is not officially affiliated with the Prestige Institute brand, rather a specific fork for the Suwanee, GA branch.

Visit the [official Prestige Institute website](https://www.prestigei.com) to find more information on SAT and ACT tutoring and aid.

## How to display the signage

Start at the main page of the repository, then locate the settings tab in the top bar. Once found, locate the pages section on the right side. When on the tab, locate the button that read "Visit the Site" and it will take you to an external URL that will display the HTML file. The [website can be found here for convenience](https://prestigesw.github.io/prestigesuwanee.display/).
