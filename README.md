# Prestige Institute Suwanee, GA Digital Signage

This repository contains the contents of a personalized digital signage for Prestige Institute's Suwanee location. Written entirely in an HTML file, this code runs locally on a browser to display information.

This is not officially affiliated with the Prestige Institute brand, rather a specific fork for the Suwanee, GA branch.

Visit the [official Prestige Institute website](https://www.prestigei.com) to find more information on SAT and ACT tutoring and aid.

## How to display the signage

If given access to the repository, start at the main page of the repository, then locate the settings tab in the top bar. Once found, locate the pages section on the right side. When on the tab, locate the button that read "Visit the Site" and it will take you to an external URL that will display the HTML file. Otherwise, the digital signage URL can be found [here](https://prestigesw.github.io/prestigesuwanee.display/) for convenience.

## Purpose
At the Prestige Institute in Suwanee, GA, the overall goal of success is for the students to have access to any supplementary material that they may need. In order to better supply the students with content, the team has made this signage to easily view vocabulary pages, future test dates, promoted programs, and room availability (in the works).

(__NOTE__: This signage is specific to the Prestige Institute located in Suwanee, GA. Certain programs may not apply if queried upon at other branches of the Prestige Institute.)
